# P1 Glass & Mess: build status (2026-10-29)

Tests H1 ("the cleaning gesture is satisfying in itself"), A/B on the gesture. Spec: [prototype-plan.md](../prototype-plan.md) §5.
Scene `Assets/Prototypes/P1_GlassMess/P1_GlassMess.unity` (menu: AquariumCiv → Agent → Prototypes → Build P1 Glass and Mess),

## Decision (2026-10-29)
The user played both variants on TestFlight build 3: **drag-to-wipe (A) is the gesture.** "That one felt amazing."
Friends' lab sessions still run to confirm or reshape it (metrics below).

## Built
| Piece | Notes |
|---|---|
| `GlassGrime` (shared) | Paintable grime mask per glass pane (CPU mask → `AquariumCiv/GlassGrime` shader, UVs from object space so both faces agree). The sim's grime value is the source of truth over time: it grows the masks unevenly (noise, bottom first); wipes paint the masks and write the mean back to the sim. Replaces P0's single tint. |
| `Juice` (shared) | Synthesized sounds (no audio assets yet): pop, chime, whoosh, cloth swish on dirty glass, squeak on clean glass. Glint particles. Same palette for both variants. Sizes are screen-relative. |
| Camera | Two fingers now rotate while pinching (both variants). A drag tool can take one-finger drags (`OrbitCamera.DragTool`), and a tap claim gets first say on taps. Right-drag rotates in the Editor. |
| **Variant A: wipe** | Drag on the glass wipes a finger-wide stroke (soft edges leave streaks for a second pass). Fast swipes across trash or weeds flick them out. Tapping mess only wiggles it, with a "swipe across it" hint. Turn the tank with two fingers or by dragging beside it. |
| **Variant B: tap** | Tapping dirty glass pops a round patch clean (pop, glint ring). Tapping trash or weeds pops them. Drag turns the tank. Taps on clean glass reach the world. |
| Lab pacing | Sim at x60, mess full in ~10 real minutes, trash ~1/min, output penalty off. Each variant starts from the same messy tank (`MessView.MakeMessy`). A hint banner explains the gesture at variant start. |
| Logging | `clean` events with gesture `wipe` / `tap` / `flick` and the voluntary flag; `full_clean` with seconds from messy to spotless; counters `wipe_strokes`, `wipe_s`, `glass_taps`, `full_cleans`, `full_clean_s`. |
| Debug panel | New row: Messy tank, Grime +0.3, Trash +3, Vines +0.3. |
| Tests | `AddMessIsCappedLikeNaturalMess` (8/8 EditMode pass). |

## Agent playtest (tester sub-agent, real touch path via InputTestFixture)
- Run 1 failed. Six real issues, all fixed: the full-clean cheer never fired after gradual cleaning; "voluntary" used
  overall mess instead of glass grime; flicks mostly missed (5/31); props were tiny with no hit area; trash spawned
  inside buildings and couldn't be reached; particles drew as squares.
- Run 2 passed. Cleaning lands under the finger on all panes. Flicks 10/10, also behind buildings. Both variants reach
  spotless and log `full_clean`. 0 console errors.
- Effort from the same messy tank (grime 0.81, vines 0.5, 6 trash): A 44 strokes, 0 turns; B 54 taps, 1 turn.
  Estimated 45–60 s at a human pace.
- Polish pass (tester run 3 passed):
  - Junk is picked by the nearest piece on screen within ~44 pt.
  - The camera pulls back on screens narrower than 9:16.
  - Trash is bigger. Toasts stay inside the screen. The banner sits below the safe area.
  - The gesture hint comes back after 25 s idle (at most 3 times).
  - Taps on faint grime pop it.
  - "Next version" moves on from a forced variant.
  - "Voluntary" is judged per pane.
  - The cheer needs every pane under 0.06 grime, and the confetti is bigger.
- Open polish:
  - In B, junk within the pick radius wins over a building under the finger.
  - The banner under a real notch is untested.
- Not checked via automation: the IMGUI survey, "Done for now", "Next version" and debug buttons. Sound by ear.

## Known gaps
- No haptics (iOS light-impact haptics need a native plugin).
- Sounds are synthesized placeholders. Kenney's CC0 audio packs are the obvious upgrade if they feel cheap.
- Only the near glass can be cleaned from any angle: reaching the other panes means turning the tank.
- Not run on a phone yet (needs the TestFlight pipeline, or an Editor lab session).
