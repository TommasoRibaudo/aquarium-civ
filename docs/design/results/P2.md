# P2 Return to Mess: build status (2026-10-29)

Tests H2 ("opening the app to find mess is a pull, not guilt; a slight output drop makes care matter without making it
a chore"). A/B on the consequence of mess. Spec: [prototype-plan.md](../prototype-plan.md) §5.
Scene `Assets/Prototypes/P2_ReturnToMess/P2_ReturnToMess.unity` (menu: AquariumCiv → Agent → Prototypes → Build P2
Return to Mess), first in Build Settings. Results (metrics, diary, survey quotes, decision) go here after testing.

## Built
| Piece | Notes |
|---|---|
| Gesture | P1's winner, drag-to-wipe, moved to `_Shared` as `WipeCleaner` (copied from P1's variant A; P1's file is unchanged so its lab build stays as tested). |
| **Variant A: cosmetic** | Mess only looks bad. Output and mood ignore it (`SimConfig.outputPenaltyEnabled` and the new `messAffectsMood` both off, so there's no "grumble" chronicle line either). |
| **Variant B: output** | Output drops linearly with mess, −25 % at full mess (the 48 h cap). The ledger shows "Mess is slowing work: −N %". Citizens get grumpy: they walk slower, idle longer, and grumble out loud above mess 0.3 ("Who left this junk here?"). |
| Economy | Unchanged shared sim: people grow, huts and other buildings appear. The ledger shows year, people, huts. |
| Welcome back | After ≥ 15 min away: a one-line summary ("You were away 8 hours. +4 people, 1 new hut, 1 new tavern.") and the crowd turns to the camera and cheers, with a chime. The generic banner is off in P2. |
| Time | Diary (default): real time at design speed, 1 real hour = 1 game year, mess full at 48 h. Real offline catch-up on launch and resume. |
| Lab | The debug panel's new **Mode: Lab/Diary** button switches this device to lab. Lab shows tester-facing **Step away +1/+8/+24/+48 h** buttons (same path as a real resume) and resets to a fresh village on each variant switch. |
| Survey | Q4 "I felt bad or guilty when I opened it". In diary mode, the survey is asked at most once per calendar day. After that, "Done for now" just ends the session. |
| Logging | New `return` event (away hours, years, people delta, new buildings, mess, output penalty), `first_clean` event + `first_clean_s` counter (time from open to first clean, any prototype), `grumbles` counter. `session_start` already has the away hours for opens/day and D2/D4. |
| Tests | `OutputPenaltyIsLinearInMess`, `MessMoodEffectFollowsTheSwitch(true/false)`; shared assembly 11/11 pass. |
